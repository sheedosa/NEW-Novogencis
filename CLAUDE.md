# Novogencis — hair restoration platform

GitHub: https://github.com/sheedosa/NEW-Novogencis
Package name: novogenics-hair-restoration

## Stack
Vite · React · TypeScript · Tailwind CSS · Firebase (hosting / backend)

## Run locally
```
npm install
npm run dev        # dev server
npm run build      # production build
```

## Notes
- Firebase config lives in `.firebaserc` / `.firebase`.
- Project docs (BACKEND.md, DESIGN_BRIEF.md, ADMIN_* etc.) sit in the repo root — useful background before making changes.
- `node_modules` can be removed anytime to save space — `npm install` rebuilds it.
